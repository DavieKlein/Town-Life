# Town Life - dialogue source (compiled by tools/story_data.py into src/tl_dialogue_data.cpp + include/tl_dialogue_ids.h).

# node <name>                 starts a node; its pages chain in order. Names with a convention are looked up by the game:
#                               greet_<npc>_<good|neutral|grumpy>   greeting at the start of small talk
#                               talk_<npc>_<topic>                  NPC answer to a small-talk topic (weather work music sports
#                                                                   gossip compliment joke complain)
#                               bye_<npc>                           farewell
#                               intro_<npc>                         first conversation ever (scripted, may have choices)
# SPEAKER[:expression]| text  (expression: neutral happy angry sad surprised; default neutral, or by mood / topic result in small talk)
# SPEAKER| text               one page (speaker: MIA ROSA DEX PIMM LOU HALLORAN DEXV VICTOR VALET PLAYER SYSTEM NPC;
#                               NPC = whoever you are talking to, PLAYER = {NAME}, SYSTEM = no portrait). The text is
#                               word-wrapped to 3 lines by the game and split into more pages if it is longer. {NAME} = the
#                               player's name. " / " is just a space (kept from the story document).
# ! effect, effect            effects of the page above (applied when the page is shown):
#                               friend <npc> <+-n>   money <+-n>   flag <name> [value]   mission <id>   done <id>   coins <n>
# ? text -> node | effects    a choice shown after the page above (2-4 per page, text up to ~24 chars); `-> end` ends the
#                               conversation; effects as above, comma separated
# goto <node>                 continue with another node after the last page
